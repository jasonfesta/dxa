# Resource directory

[Home](../README.md) · [Agents](agents.md) · [MCPs](mcps.md) · [Skills](skills.md) · [Research](papers.md)

Find a resource by the work you want to do. An agent carries out tasks; a workspace provides an environment for that work; an MCP connects an assistant to a tool; a skill supplies reusable instructions.

## Evidence

| Label | Meaning |
| --- | --- |
| Source reviewed | The linked primary documentation was read. Capabilities are the creator's documented claims. |
| Setup checked | Installation, connection, or build was checked in a named environment. This does not establish output quality. |
| Workflow tested | A named task was completed and its output inspected. The record must include the date, environment, result, and limitations. |

The first edition is a source-reviewed directory. No third-party resource is labeled workflow tested. Earlier local setup checks are described separately where useful.

Official means maintained by the product or project team. Community means an independent integration or contribution. Neither describes test quality. Availability and supported clients can change; follow the linked setup documentation.

## Selection

A featured resource should have a clear use in product exploration, design systems, agent interaction, creative production, or review. Prefer editable results and useful integration with a designer's existing tools. List a distinct alternative when it changes the workflow, not just the brand name.

The directory is curated and growing. It is not an exhaustive list of every design tool.

## Maintenance

Review links and material capability changes before each DxA event. After an event, connect published demos to the relevant entries and record changes in [Updates](updates.md). This is an editorial practice, not an automated monitor.

Additions should follow [CONTRIBUTING.md](../CONTRIBUTING.md).
